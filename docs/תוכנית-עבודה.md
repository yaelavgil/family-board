# 🗺️ תוכנית עבודה — Family Board

## החזון
לוח משימות משפחתי אחד, בהשראת Jira אבל בגובה של בית: יעל ורועי מתכננים יחד בזמן-אמת, גור, דני ולילי מקבלים משימות, מסמנים ביצוע וצוברים נקודות. חי על הטלפונים ועל טאבלט במטבח של הבית החדש.

## המשתמשים
| מי | צורך עיקרי | מצב תצוגה |
|---|---|---|
| יעל | ניהול הכול, תכנון שבועי, אישור מטלות | קנבן מלא + ניהול |
| רועי | תכנון משותף במקביל, המשימות שלו | קנבן מלא |
| גור, דני, לילי | "מה שלי להיום", סימון ביצוע, נקודות ופרסים | מצב ילד — כרטיסים גדולים |

## פיצ'רים

### MVP (גרסה 1)
- לוח קנבן: **לביצוע → בתהליך → ממתין לאישור → בוצע**, גרירה חופשית
- משימה: כותרת, אחראי/ת (אווטאר), תאריך יעד, קטגוריה, הערות, נקודות
- תצוגת "שלי" לכל בן משפחה + פילטור לפי אדם/קטגוריה
- Quick-add תמידי (כמו Linear) + עריכה בנגיעה
- סנכרון זמן-אמת בין כל המכשירים (Firestore listeners)
- בחירת פרופיל בכניסה (בלי סיסמאות לילדים), צבע ואווטאר לכל אחד
- עברית RTL, מובייל תחילה, PWA להתקנה על מסך הבית

### גרסה 2 — שכבת הילדים
- נקודות לכל מטלה + חנות פרסים שההורים מגדירים (כלכלה מאוזנת: 25/50/150)
- זרימת אישור: ילד מסמן "סיימתי" → הורה מאשר → נקודות נזקפות
- סטריקים, תג שבועי, חגיגת קונפטי 🎉
- מטלות חוזרות (כל יום/שבוע, רוטציה בין ילדים)

### גרסה 3 — איכות חיים
- תבניות ("ערב בי"ס", "שישי נקי"), לוח שבועי מודפס
- התראות (מטלה באיחור, "ממתין לאישור")
- ייבוא המשימות מהלוח הקיים (הארטיפקט) + ארכיון
- מצב טאבלט-מטבח (תצוגת קיר, בהשראת Skylight)

## ארכיטקטורה

**המלצה: אתר סטטי על GitHub Pages + Firebase Firestore (חינם) לסנכרון.**

- Frontend: Vanilla JS/HTML/CSS יחיד וקליל (כמו home-picks ו-wishlist-ida הקיימים) — RTL, בלי build step
- State: Firestore בזמן-אמת; מבנה: `families/{familyId}/tasks/{taskId}`, `members`, `rewards`, `activity`
- זיהוי: Firebase Anonymous Auth + קוד משפחה (familyId סודי בקישור) — הילדים בוחרים פרופיל, בלי חשבונות
- אבטחה: Security Rules שמגבילות קריאה/כתיבה למחזיקי ה-familyId; אפס מידע אישי בריפו הציבורי
- חלופה שנשקלה ונדחתה: המשך על Claude Artifact — מצוין לשימוש של יעל, אבל דורש חשבונות claude לכל בני הבית ולא מתאים לילדים

## עיצוב
ממשיכים את שפת "הלוח של יעל" (Karantina + Assistant, זית/רימון על נייר חם, בהיר+כהה) — עם צבע זהות לכל בן משפחה. עיצוב מפורט יגובש בשלב 2.

## סיכונים והחלטות פתוחות
- **Firebase דורש הקמה חד-פעמית ע"י יעל** (חשבון Google) — חוסם את שלב 1
- מגבלות חינם של Firestore מספיקות בשפע למשפחה אחת
- אימוץ ע"י הילדים — מטופל בפיילוט הדרגתי ובשכבת המשחק
- תזמון: פרויקט צד לתקופה עמוסה (מעבר דירה + פולין) — אין דדליין; ההשקה הביתית הגיונית אחרי החזרה מפולין (סוף ספטמבר)
